# 签到助手 v0.3

个人 Chrome 扩展，非 Monash 官方产品。学生正常登录学校网站、手动输入老师公布的签到码后，扩展按课次填写并提交原始表单。

## 先看预览

打开单独提供的 `attendance-helper-preview.html`，或本文件夹中的 `preview.html`，即可体验；预览使用模拟课程，不能提交真实签到。

- 输入普通文字：模拟成功。
- 输入 `error`：模拟签到码错误。
- 输入 `unknown`：模拟结果不明确，仍继续处理其他已填写课次。

## 安装到 Chrome

1. 地址栏打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择这个仓库的根目录（包含 `manifest.json`）。
3. 在浏览器工具栏点击“签到助手”，打开学期视图。

不需要安装 Node.js、Python 或运行构建命令。安装方法参考 [Chrome 官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)。

## 使用

1. 在同一个 Chrome 用户配置中打开 <https://attendance.monash.edu.my/student/>，完成学校登录。
2. 在扩展中点击“连接签到网页”。扩展从学校页面读取学期日期、近期课次和对应入口。
3. 设置 Week 1 的第一天、教学周数（1–52）、Mid break 开始日期（可留空）。Mid break 固定为连续 7 天，不计入教学周。
4. 展开教学周，在每节课右侧输入签到码。最后点击“提交已填写的签到码”。空白项跳过，已填写项按课次依次提交。
5. 阅读逐节反馈。每节课分别显示结果，失败或待确认不阻断后续课次；结果不明确时不自动重试。签到码错误可以直接修改后重新提交。

## 周视图与截止时间

- 每次连接扫描页面内所有日期的课程（包括无链接的已签到及未开课课程），只用马来西亚时间当前自然周的课表生成当周及后续周；历史周保留已读取的实际记录，不用新课表回填。
- 按用户提供的规则：截止时间是该课下一周同一天、同一上课时间，使用马来西亚 UTC+08:00；Mid break 不延长这个 7 日期限。
- 过期课次禁用并灰显；一周中仍有未过期课次时，那些课次仍可填写。
- 学校未提供对应日期的真实入口时不能提交，不会使用其他周的链接替代。
- `?`：尚未完成、未开放或结果不明确。
- 红色 `×`：至少一节课当前无法签到，或收到明确失败反馈。**这个图标不等于学校认定缺勤。**
- 绿色 `✓`：本周全部课次都有明确的完成证据。
- `–`：尚未读到课程。

## 本版范围

- 页面结构按开发时实际看到的 Monash 签到页适配；网站改版可能需要更新。
- 学校只公开近期入口和汇总出勤率，不能据此还原全部历史课次是否签到。未获取到的历史周灰显并标记“历史记录未读取”，不会虚构早期课表。
- 已在其他地方完成的签到，如果网页没有提供可识别的逐节状态，本版不会仅凭总出勤率标绿。
- 课程和逐节结果按账户、学期保存到浏览器本地记录库，重新连接同一账户会恢复；签到码仅保留在页面内存中。清除扩展数据或卸载扩展会删除本地记录。
- 仅请求该签到域名的页面操作权限及本地设置存储权限。不读取 Cookie，不保存学校密码或签到码，不上传到额外服务器。
- 已检查日期、Mid break、精确 7 日截止、课次匹配、记录恢复及模拟批量提交流程；用户已确认旧版真实提交可用。本次更新读取了真实页面结构，提交成功、错误和不明确的批量流程在模拟环境验证，未代用户发送真实签到。

## 总签到率与 PASS

- 总签到率直接读取学校首页，不使用扩展自行计算的平均值；连接和批量处理结束后刷新。低于 80% 标红并显示 AskMira 链接，读取不到时显示“暂未读取”。
- PASS 根据课程名称中的独立单词 PASS 识别，默认关闭参与签到，仍显示课次；开启后按普通课程处理。该开关不会改变官方总签到率。
- 批量按顺序操作原始表单，每次点击处理全部已填写项。旧版只识别文字反馈，遇到不明结果最多等待约 10 秒后停止；新版在页面返回课程列表时核对对应课次的官方对号，并继续队列。一般文字反馈立即返回，未识别反馈轮询最多约 4 秒后核对列表；学校页面加载时间仍取决于网络和学校服务器。

## 文件

- `manifest.json` / `background.js`：扩展入口。
- `app.html` / `app.css` / `app.js`：学期界面及批量提交。
- `store.js`：按账户和学期保存课表及结果；当前周课表更新。

## 多账户使用（v0.3.1）

- 先连接学校账户再编辑设置。开学日期、教学周数、Mid break、PASS 开关与课程记录一起按“学校显示的账户名称＋学期”分别保存。
- 切换账户或学期后自动加载对应设置；新账户使用学校学期起始日期、12 周、无 Mid break、PASS 关闭作为默认值。重新连接原账户可恢复原来的设置。
- 旧版共用设置没有账户归属，不会自动迁移给某个账户；升级后请连接并为当前账户重新保存一次。
- 每节课提交前重新向学校首页读取当前登录账户，并在填写原始表单时再次检查页面账户。账户变化、登录失效或无法核实会终止剩余队列、清空内存中的签到码并要求重新连接；普通错误码仍可继续其他课次。
- 当前学校页面提供的是显示名称，未读取到可用的唯一账号 ID；完全同名的不同账户仍无法可靠区分。
