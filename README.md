# 签到助手 v0.2

个人 Chrome 扩展，非 Monash 官方产品。学生正常登录学校网站、手动输入老师公布的签到码后，扩展按课次填写并提交原始表单。

## 先看预览

打开单独提供的 `attendance-helper-preview.html`，或本文件夹中的 `preview.html`，即可体验；预览使用模拟课程，不能提交真实签到。

- 输入普通文字：模拟成功。
- 输入 `error`：模拟签到码错误。
- 输入 `unknown`：模拟结果不明确，暂停后续提交。

## 安装到 Chrome

1. 地址栏打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择这个仓库的根目录（包含 `manifest.json`）。
3. 在浏览器工具栏点击“签到助手”，打开学期视图。

不需要安装 Node.js、Python 或运行构建命令。安装方法参考 [Chrome 官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)。

## 使用

1. 在同一个 Chrome 用户配置中打开 <https://attendance.monash.edu.my/student/>，完成学校登录。
2. 在扩展中点击“连接签到网页”。扩展从学校页面读取学期日期、近期课次和对应入口。
3. 设置 Week 1 的第一天、教学周数（1–52）、Mid break 开始日期（可留空）。Mid break 固定为连续 7 天，不计入教学周。
4. 展开教学周，在每节课右侧输入签到码。最后点击“提交已填写的签到码”。空白项跳过，已填写项按课次依次提交。
5. 阅读逐节反馈。遇到结果不明确时自动暂停，不自动重试；检查学校网页后，可刷新课程再处理剩余项目。

## 周视图与截止时间

- 按从近期页面读到的固定课表，重复生成整个学期的课程时间、课程代码、活动类型和编号。
- 按用户提供的规则：截止时间是该课下一周同一天、同一上课时间，使用马来西亚 UTC+08:00；Mid break 不延长这个 7 日期限。
- 过期课次禁用并灰显；一周中仍有未过期课次时，那些课次仍可填写。
- 学校未提供对应日期的真实入口时不能提交，不会使用其他周的链接替代。
- `?`：尚未完成、未开放或结果不明确。
- 红色 `×`：至少一节课当前无法签到，或收到明确失败反馈。**这个图标不等于学校认定缺勤。**
- 绿色 `✓`：本周全部课次都有明确的完成证据。
- `–`：尚未读到课程。

## 本版范围

- 页面结构按开发时实际看到的 Monash 签到页适配；网站改版可能需要更新。
- 学校只公开近期入口和汇总出勤率，不能据此还原全部历史课次是否签到。未获取到的历史周按无法签到显示。
- 已在其他地方完成的签到，如果网页没有提供可识别的逐节状态，本版不会仅凭总出勤率标绿。
- 本版的课程缓存与逐节反馈保留在当前助手页面中；重新打开页面后需要重新连接。只有日历设置持久保存到本机。
- 仅请求该签到域名的页面操作权限及本地设置存储权限。不读取 Cookie，不保存学校密码或签到码，不上传到额外服务器。
- 已检查日期、Mid break、精确 7 日截止、课次匹配和模拟批量提交流程；**尚未使用有效签到码完成学校系统的真实提交验证，也没有代用户提交任何实际签到。**

## 文件

- `manifest.json` / `background.js`：扩展入口。
- `app.html` / `app.css` / `app.js`：学期界面及批量提交。
- `weeks.js`：固定课表、教学周、截止时间和状态汇总。
- `page.js` / `browser.js`：读取学校页面、核对课次、操作原始表单。
- `demo.js`：本地交互预览的模拟数据。
